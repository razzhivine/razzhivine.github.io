Open-source

BitrixBox

Shell · Docker · CLI

Локальный 1С-Битрикс в Docker одной командой bx: ставит окружение (PHP, nginx, MySQL или MariaDB), включает HTTPS, проходит мастер установки без браузера, убирает демо-данные, делает снимки и откатывает их. Сайт переносится из резервной копии или по SSH, с обезличиванием персональных данных. Автотесты в GitHub Actions на матрице редакций, версий PHP и баз данных.

github.com/razzhivine/bitrixbox

custom/rest

PHP · Composer · REST

Headless REST API для сайта на Битриксе: контент инфоблоков, поиск, веб-формы, справочники highload-блоков и карта сайта для фронтенда на Vue или Nuxt. Наружу уходит только публичное по белому списку. Кеш с тегами, ETag/304, лимиты, защита форм и описание в OpenAPI. Подключается через Composer.

github.com/razzhivine/custom-rest
